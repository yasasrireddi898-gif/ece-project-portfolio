# ESP32 Temperature Monitoring System

## Overview
A beginner-friendly Electronics and Communication Engineering project that monitors temperature using an ESP32 and a DHT22 temperature and humidity sensor.

## Objective
To read temperature values and identify when the temperature is above or below a chosen threshold.

## Components
- ESP32 microcontroller
- DHT22 temperature and humidity sensor
- Wokwi online simulator

## Working Principle
The DHT22 sensor provides temperature readings to the ESP32. The program checks the measured temperature against predefined thresholds to identify high and low temperature conditions.

## Features
- Reads temperature values from the DHT22 sensor
- Checks temperature against defined limits
- Allows testing without physical hardware

## Platform
Wokwi Simulator

## Learning Outcomes
- Basics of ESP32 programming
- Reading sensor data
- Using conditional statements
- Testing an ECE project through simulation
